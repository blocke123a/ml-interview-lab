# ML Interview Lab

An interactive Streamlit study app for data science and machine learning interviews.

This repository is intentionally a **learning scaffold**. Navigation, styling, and guided exercises are included, while many mathematical functions, models, and visualizations are left unfinished so you can build them yourself.

## Topics

- Gradient descent
- Linear regression
- Ridge and Lasso
- Bias–variance
- Logistic regression
- Bayesian updating
- Neural networks from scratch
- Model evaluation

## Run locally

```bash
pip install -r requirements.txt
streamlit run app.py
```

## Recommended workflow

1. Open one topic page.
2. Read the TODO comments.
3. Implement from first principles.
4. Make the visualization interactive.
5. Compare with scikit-learn / SciPy.
6. Write your own explanation.
7. Answer the interview prompt.
